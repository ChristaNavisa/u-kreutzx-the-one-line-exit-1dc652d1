Entry for the make.fun bounty [The One-Line Exit](https://make.fun/c/u-kreutzx-the-one-line-exit-1dc652d1): a program that writes the funniest single-line resignation letter it can to `/output/entry.txt`.

## Run

```sh
node main.ts
```

It writes exactly one line (1–140 characters, UTF-8) to `/output/entry.txt`.

## The line

> I hereby resign as your barista: I have been promoted to customer.
